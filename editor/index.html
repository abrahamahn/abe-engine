Ganbate Studio — Quick-Start & Architecture Guide

Unified 3D World Authoring, Live Game Output Verification (PIE), and Full-Repository Project X-Ray

1. 3D Viewport & Gizmo Controls

  • Right-Click + Drag: Orbit 3D camera around target
  • Middle-Drag or Shift + Right-Drag: Pan camera
  • Mouse Scroll Wheel: Zoom in / out smoothly
  • Left-Click: Select 3D entity or drag gizmo axis
  • W / E / R: Move / Rotate / Scale gizmo (hold Ctrl/Cmd to snap)
  • F: Frame selected entity (or entire scene)
  • Ctrl+S / Ctrl+Z / Ctrl+Shift+Z: Save / Undo / Redo

2. Matching Edit-to-Real Game Output (WYSIWYG)

  • Scene: Direct 3D engine authoring viewport (`3D World & Look`).
  • Game (PIE): Runs the real live web runtime inside exact device dimensions (`390×844` iPhone Portrait, `844×390` Landscape, `1440×900` Desktop).
  • Device Matrix: Shows 4 real aspect ratios simultaneously so portrait/landscape camera & HUD mismatches are caught immediately.
  • Preset Selector: Compare Engine Runtime vs Legacy Default side-by-side.

3. Project X-Ray (Assets + Backend/Frontend Code)

  • Overlap Clusters: Side-by-side comparison of duplicate `.glb` models (full WebGL2 textured + Clay + Wireframe + Bust zoom), environments, and editor tools.
  • Code Tree & Backend: Browse every Rust, SQL, Protocol, Shared, Frontend, and Engine source file with static risk flags (`>1,000 LOC`, `0 callers`, uncalled routes).
  • File-by-File Audit Queue: Step file-by-file (`← Prev / Next →`) and mark Keep, Update, Merge, or Delete with live source inspection.

4. Bottom Asset Browser & Workbenches

  • Assets Dock (Bottom): Double-click `.scene.json` to open a 3D scene, `.glb` to inspect in Model Studio, or drag any `.glb` / `.prefab.json` directly into the 3D viewport.
  • Inspector (Right): Edit transforms, lights, cameras (`Look through` / `Align camera`), materials, and schema-validated `.data.json` documents.
  • SceneScript (`.gbs` Bar): Type deterministic scene commands (`spawn`, `move`, `snap`) and run Verify.
